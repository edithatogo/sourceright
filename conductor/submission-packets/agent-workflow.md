# Agent Workflow Submission Packet

## Requirements Evidence

- Add A Workflow When: submission readiness, evidence refresh, and approval
  gates change.
- Add A Skill Or Agent When: a repeatable host or registry workflow has stable
  read-only contracts and human review boundaries.

Tracks 73-81 define the submission requirements, MCP directory hardening,
citation-manager and journal-platform publication boundaries, AI-client host
packages, and arXiv upstream evidence. This packet keeps those surfaces
machine-readable without treating local preparation as external acceptance.

## Local Gates

- `scripts/verify-submission-readiness.ps1`
- `conductor/submission-requirements.json`
- `conductor/submission-inventory.json`

## Draft

The packet records a stable host package and its evidence requirements. A
prepared package is not an accepted marketplace, registry, or upstream
submission.

## Approval Gate

Explicit approval is required before any external submission is created.

## Blockers

- External acceptance, maintainer response, credentials, and hosted checks are
  tracked separately from local package readiness.
- No agent or workflow submission evidence has been recorded yet.
- No agent or workflow submission is created automatically by this packet.
